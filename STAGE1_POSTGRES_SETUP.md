# Этап 1: Postgres + pgweb + миграция данных

## 1. Добавить Postgres в проект на Railway

1. Открой свой проект на Railway (тот же, где сейчас работает бот)
2. **+ New** → **Database** → **Add PostgreSQL**
3. Дождись, пока сервис поднимется (обычно ~10-20 секунд)

## 2. Создать таблицы

1. Открой сервис **Postgres** → вкладка **Data** (или **Query**)
2. Вставь и выполни содержимое файла `schema.sql` — создаст все 4 таблицы
   (`users`, `client_base`, `attachments`, `add_requests`)

Если вкладка Data неудобна — можно то же самое сделать через pgweb (шаг 3) после его установки.

## 3. Развернуть pgweb (для удобного редактирования базы)

1. В том же проекте на Railway: **+ New** → **Template** → в поиске набери **pgweb**
2. Выбери шаблон **pgweb** от Railway → **Deploy**
3. Railway сам подключит его к твоей базе Postgres через переменные окружения
4. После деплоя открой сгенерированный `.up.railway.app` адрес pgweb —
   попросит логин/пароль (задаются в переменных `PGWEB_AUTH_USER` / `PGWEB_AUTH_PASS`
   сервиса pgweb, можно посмотреть/изменить во вкладке Variables)
5. Внутри увидишь все 4 таблицы — можно просматривать, редактировать, добавлять
   строки прямо в браузере, как в таблице

## 4. Перенести существующие данные

1. Открой свою Google Таблицу
2. Лист **"Пользователи"** → **Файл → Скачать → Значения, разделённые запятой (.csv)**
   → сохрани рядом со скриптом `migrate_from_csv.py` под именем `users.csv`
3. Лист **"Клиентская база"** → так же → сохрани как `client_base.csv`
4. На своём компьютере, в папке `telegram-bot`:
   ```powershell
   pip install psycopg2-binary --break-system-packages
   ```
   (на Windows обычно без флага `--break-system-packages`, просто `pip install psycopg2-binary`)

5. Возьми строку подключения: Railway → сервис **Postgres** → вкладка **Variables** →
   скопируй значение **`DATABASE_PUBLIC_URL`** (не `DATABASE_URL` — та работает только
   изнутри Railway, а скрипт запускается с твоего компьютера)

6. Запусти миграцию:
   ```powershell
   python migrate_from_csv.py "postgresql://postgres:пароль@адрес.railway.app:порт/railway"
   ```
7. В консоли должно появиться:
   ```
   ✅ Пользователи: перенесено N строк
   ✅ Клиентская база: перенесено M строк
   🎉 Миграция завершена.
   ```
8. Проверь через pgweb, что данные на месте (открой таблицы `users` и `client_base`)

---

## Когда этот этап завершён — напиши, и перейдём к Этапу 2:
переписыванию `api.py`, чтобы бот обращался напрямую к Postgres вместо
Google Apps Script. После этого Google Таблицу можно будет полностью убрать
из процесса (заявки на добавление/прикрепление начнут падать в Postgres,
смотреть их сможешь через pgweb).
