# Telegram-бот "Управление ТТ"

Классический бот на кнопках (без Mini App / без веб-фронта). Бэкенд —
твой существующий Google Apps Script (`script.txt`), **без изменений**.

## Сценарий целиком

1. `/start` → логин агента → пароль → `action: login`
2. Бот просит ИНН → `action: check_inn`
   - Если точка **найдена** → сразу сценарий "Прикрепление"
   - Если **не найдена** → сценарий "Добавление"
3. **Прикрепление**: дни визита (кнопками, до 3) → подтверждение → `action: attach`
4. **Добавление**: название → адрес → телефон → регион → область → округ →
   район → формат → канал → тип → категория → код доставщика (все зависимые
   select'ы — кнопками, с постраничным листанием для длинных списков) →
   дни визита → комментарий → подтверждение → `action: add_tt`
5. После успешной отправки:
   - Пользователю — короткое сообщение об успехе
   - Админу (`ADMIN_ID`) — полная карточка заявки красивым текстом
   - Бот возвращает пользователя к шагу "Введите ИНН" — можно сразу
     обрабатывать следующую точку без повторного логина

`/cancel` в любой момент — прерывает текущий сценарий и возвращает к вводу ИНН
(если уже залогинен) либо к `/start`.

`/back` — возвращает на один шаг назад в текущем сценарии (например, если
выбрал не тот регион — `/back` вернёт к выбору региона заново, не сбрасывая
остальной прогресс).

## ⚠️ Обязательно перед запуском: обнови Google Apps Script

Добавлен новый шаг — геометка (широта/долгота), которую пользователь отправляет
через Telegram после ввода названия клиента. Чтобы координаты попадали в таблицу,
нужно заменить код в твоём Apps Script на версию из файла
**`google_apps_script_UPDATED.txt`** (там всего одна новая строка `data.geo`
в функции `add_tt`).

Также добавь новую колонку **"Геометка"** в лист **"Добавление"** сразу после
колонки "Название клиента" (иначе данные внутри таблицы сдвинутся не туда).

Как обновить скрипт:
1. Открой свою Google-таблицу → **Расширения → Apps Script**
2. Выдели весь текущий код и удали
3. Вставь содержимое `google_apps_script_UPDATED.txt`
4. Сохрани (значок дискеты) → **Развернуть → Управление развертываниями** →
   редактировать текущее развертывание → **Развернуть** (URL остаётся тем же,
   менять `WEB_APP_URL` в `.env` / Railway не нужно)


## Локальная установка (для разработки/теста)

```bash
cd telegram-bot
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
copy .env.example .env       # и заполнить BOT_TOKEN, ADMIN_ID, WEB_APP_URL
python bot.py
```

⚠️ Пока запущено так — бот работает только пока открыт терминал.
Для постоянной работы (24/7, без открытого терминала и включённого ПК) — деплой на Railway ниже.

## Файлы проекта

- `bot.py` — все хендлеры и сценарии
- `states.py` — FSM-состояния (Auth, Inn, Attach, Add)
- `data.py` — справочники (регион/область/округ/район/формат/канал/тип/
  категория/код доставщика) — **редактируются прямо здесь**, если нужно
  поменять значения списков
- `keyboards.py` — генераторы inline-клавиатур (с пагинацией для длинных списков)
- `api.py` — обращения к Google Apps Script
- `Procfile`, `.python-version` — нужны для деплоя на Railway

## Деплой на Railway.app (бот работает 24/7, ПК можно выключать)

### 1. Залить проект на GitHub

В папке `telegram-bot`:
```bash
git init
git add .
git commit -m "Первая версия бота"
```

Создай пустой репозиторий на https://github.com/new (например `telegram-bot`), затем:
```bash
git remote add origin https://github.com/ТВОЙ_НИК/telegram-bot.git
git branch -M main
git push -u origin main
```

⚠️ Файл `.env` в git не попадёт (он в `.gitignore`) — это правильно, токен не должен быть в публичном репозитории.

### 2. Создать проект на Railway

1. Зайти на https://railway.app → войти через GitHub
2. **New Project** → **Deploy from GitHub repo** → выбрать репозиторий `telegram-bot`
3. Railway сам определит Python-проект по `requirements.txt` и найдёт `Procfile`

### 3. Задать переменные окружения

В проекте на Railway → вкладка **Variables** → добавить те же переменные, что были в `.env`:
```
BOT_TOKEN=твой_токен
ADMIN_ID=твой_id
WEB_APP_URL=ссылка_на_google_apps_script
```

### 4. Проверить деплой

Вкладка **Deployments** → дождаться статуса **Success**.
Вкладка **Logs** — там должно быть тихо, без ошибок (это нормально, бот просто слушает).

Напиши боту `/start` в Telegram — он должен ответить, даже если твой ПК выключен.

### 5. Обновление бота в будущем

Просто:
```bash
git add .
git commit -m "описание изменений"
git push
```
Railway автоматически передеплоит новую версию.

⚠️ Если после этого будешь ещё и локально запускать `python bot.py` на своём ПК —
получишь ошибку `TelegramConflictError` (два процесса одного бота одновременно).
Как только бот задеплоен на Railway — локально его больше не запускай, только редактируй код.
